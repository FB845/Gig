            カレンダー → 予定CALENDAR → PLANNER

            Bring blocks and shifts you've already scheduled into Log → Plan: an .ics calendar file (Google / Apple / Outlook export) or a screenshot of your schedule (e.g. the Flex calendar). You review everything before it's added; past events are skipped.

            スクショ取込 · 収入SCREENSHOT (OCR)

            Snap or upload a screenshot of your Flex or Dasher earnings screen. The app reads the amounts, miles and counts for you to review before saving.

            CSV 取込CSV IMPORT

            Import an earnings CSV (e.g. DoorDash weekly earnings export, or any spreadsheet with date/earnings/miles columns).

            メール取込EMAIL-ASSISTED

            Amazon Flex and DoorDash email you every payout. Ask Claude (with your Gmail connected) to pull those deposit emails and generate a CSV, then import it above. Amazon Flex and DoorDash don't offer a public driver API, so this is the closest thing to automatic.

            Plan on desktop, log on your phone — every shift, plan and expense syncs on its own, so edits on both devices merge instead of overwriting. Optional; the app works fully on-device without it.

            1. Create a free project at console.firebase.google.com, add a Web app and copy its firebaseConfig.
            2. Authentication → Sign-in method: enable Google (and Email/Password if you want it). Under Settings → Authorized domains, add this site's domain.
            3. Firestore Database: create a database, then set Rules to:
            rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /users/{uid}/{doc=**} {
      allow read, write: if request.auth != null
                         && request.auth.uid == uid;
    }
  }
}
